## Works where your agent works

In Claude Code it is a plugin: a Read hook swaps the pixels for the words
automatically. Everywhere else it is one MCP server with three tools.

## Install

```sh
brew install all-caps-dev/tap/cheapshot
```

Universal binary, notarized, macOS 13 or later. MIT.
[Read the introduction](/cheapshot/introduction/) for the build-from-source route and what to do first.
