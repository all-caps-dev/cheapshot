## One screenshot, in numbers

An image costs roughly `(width x height) / 750` tokens, and it stays in the
conversation, riding along on every later turn. Measured on a real screenshot:

## Why Cheapshot

<CardGrid stagger>
  <Card title="No model in the loop" icon="laptop">
    OCR runs on Apple's Vision framework, on device. Nothing is uploaded to read a
    screenshot, and nothing is paid for.
  </Card>
  <Card title="Secrets redacted first" icon="seti:lock">
    AWS keys, GitHub tokens, OpenAI keys, Slack tokens, JWTs, PEM blocks and bearer
    headers become `[AWS_KEY]`, `[GITHUB_PAT]` and so on before any text reaches the
    model. Add your own rules as JSON.
  </Card>
  <Card title="Screenshots of code stay code" icon="seti:code">
    Fixed-width regions are wrapped in a fence with their indentation rebuilt from
    the bounding boxes, and recognized with language correction off so hashes and
    tokens are not "corrected" into words.
  </Card>
  <Card title="Video and PDF too" icon="seti:video">
    A screen recording becomes a timestamped transcript of only the frames that
    changed. A PDF uses its text layer, and falls back to OCR on a page whose text
    is garbled.
  </Card>
  <Card title="A ledger you can show" icon="list-format">
    Every run appends one JSON line: image tokens, text tokens, saved, redactions.
    Split it by screenshot, video and PDF before anyone turns it into dollars.
  </Card>
  <Card title="Structured when you need it" icon="seti:json">
    `--json` returns the text, each line with its box, redaction counts, and for a
    PDF the page numbers and file hash, so an agent can cite line 42 of a screenshot.
  </Card>
</CardGrid>

## Works where your agent works

In Claude Code it is a plugin: a Read hook swaps the pixels for the words
automatically. Everywhere else it is one MCP server with three tools.

## Install

```sh
brew install all-caps-dev/tap/cheapshot
```

Universal binary, notarized, macOS 13 or later. MIT.
[Read the introduction](/cheapshot/introduction/) for the build-from-source route and what to do first.
