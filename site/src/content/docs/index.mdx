import { Aside, Card, CardGrid } from '@astrojs/starlight/components';

<p class="hero-note">Runs on any Mac made after 2019 running macOS 13 or later.</p>

<div class="three-up">
<CardGrid>
  <Card title="Savings grow with every turn" icon="document">
    An image is sent again on every later turn. On a real screenshot, 1,018 image
    tokens became 37 text tokens.

    The [ledger](/cheapshot/ledger/) counts each image once, so a long conversation
    saves more than it shows. Over a 50 turn conversation:
    **50,900 tokens sent as pixels, 1,850 sent as words.**
  </Card>
  <Card title="Fast redaction locally, no LLMs!" icon="seti:lock">
    Upload a screenshot and every key in it is now in a provider's logs, forever.
    Cheapshot replaces API keys, tokens, passwords and private hostnames with
    `[AWS_KEY]` style labels on your Mac, before any text leaves it.

    [How redaction works](/cheapshot/redaction/).
  </Card>
  <Card title="Screenshots, PDFs and recordings" icon="seti:video">
    PNG, JPEG, WebP, GIF and PDF, plus any video ffmpeg can open. A recording is
    read only where the screen changed: a 51 minute 4K talk became a 17 screen
    transcript in 35 seconds on an M4 Pro Mac mini, **31,348 image tokens to
    1,133, 96% saved.**

    [How video works](/cheapshot/video/).
  </Card>
</CardGrid>
</div>

<Aside type="caution" title="Redaction is best-effort, not a guarantee">
OCR can garble a secret and the rules can miss it, so don't point Cheapshot at
anything that must never leak.
[What redaction does not promise](/cheapshot/redaction/#what-redaction-does-not-promise).
</Aside>
