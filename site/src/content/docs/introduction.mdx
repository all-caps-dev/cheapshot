Models with vision often don't need an entire image. A terminal, an error dialog
or a settings pane is only words, and the words cost a small part of what the
image costs. [Models without vision still benefit](#models-that-cant-read-images).

<Aside type="tip" title="Cheapshot works best with knowledge work, code, and screenshots full of text">
Instead of sending thousands of pixels per sentence it sends the actual text
with redactions itself. [Redaction](/cheapshot/redaction/) explains what gets
redacted and what it can miss.
</Aside>

When the Claude Code plugin finds no text in an image, it lets the image load the normal way. When an image has some text and the
visual matters, the agent can ask for the image with
[`cheapshot allow`](/cheapshot/claude-code/#the-escape-hatch). A model with no
vision still can't interpret the visual.

Works with Claude Code as a [plugin](/cheapshot/claude-code/), and with Cursor,
Cline, Codex, OpenCode, pi and oh-my-pi through the [MCP server](/cheapshot/mcp/).

[Install it](/cheapshot/install/) with Homebrew, by asking your agent, or from source.
[Use](/cheapshot/use/) covers the commands.

## Savings grow with every turn

A screenshot costs roughly `(width x height) / 750` tokens, and rides along on
every later turn. A 4 megapixel capture, one Retina laptop screen, is about
4,800 tokens. The words are usually all the agent needed. On a real screenshot,
**1,018 image tokens became 37 text tokens, 96% saved.**

A model has no memory between turns, so every time you hit enter, the whole
conversation is read again from beginning to end, every turn, including every
image you pasted. You pay for a screenshot on every
turn until the session ends. So do you want to send 1,018 image tokens or 37
text tokens?

The table shows that one screenshot over a long conversation, if the conversation
is never compacted.

| Turns in the conversation | Sent as pixels | Sent as words | Tokens saved |
|---|---|---|---|
| 1 | 1,018 | 37 | 981 |
| 10 | 10,180 | 370 | 9,810 |
| 50 | 50,900 | 1,850 | 49,050 |
| 100 | 101,800 | 3,700 | 98,100 |

Larger screenshots save more. On Claude 4.7 and later models, one 4 megapixel
screenshot is about 4,800 tokens. Over a 50 turn session it is sent 50 times,
roughly 240,000 input tokens for one picture. Paste five screenshots in an
afternoon of debugging and the pixels alone are more than a million input tokens
of resend.

Prompt caching lowers the price of the resend, but it does not shrink the
context the images occupy. A long session hits the context window sooner, gets
compacted sooner, and loses earlier work sooner, and the images are the
heaviest thing in it. The words are a few lines of text that cost almost
nothing to carry.

The [ledger](/cheapshot/ledger/) counts each image once, when Cheapshot reads it.
It doesn't count the resends, so a long conversation saves more than
`cheapshot --ledger` shows.

## Models that can't read images

Not every LLM can read an image. On 2026-11-05,
[OpenRouter's model list](https://openrouter.ai/api/v1/models) showed 144 of 454
models with no image input. A model with no image input can't open a screenshot
or a scanned PDF. Cheapshot turns the file into text on your Mac, so the model
can read the words.
